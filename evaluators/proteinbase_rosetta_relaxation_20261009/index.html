How these models were built · inputs and learned coefficients
Why one or four features? What about two and three?

This experiment asked whether changing Rosetta preparation improves an existing evaluator. The single-feature model isolates Rosetta energy; the four-feature model replaces only Rosetta in the original combined classifier. These sizes were prespecified controls, not a search for the best feature count.

Two- and three-feature models are reasonable: the four channels give six pairs and four triples. They have not been trained in this comparison. A smaller subset could reduce redundant or unhelpful inputs, but that must be measured.

For a separate subset study, keep the outer family-held-out tests, choose the subset using family-grouped validation entirely inside each training set, and evaluate the selected model once on its outer test. Comparing original and relaxed Rosetta would use the same subsets and splits. These datasets have already been inspected, so this would remain retrospective evidence; a fresh dataset is needed for independent confirmation.

Historical four-feature results include FoldX. A future FoldX-free Arena evaluator needs its own evaluation; removing a feature does not preserve the old model’s reported performance. No new combinations, fitting, thresholds or molecular computations are included in this report update.
